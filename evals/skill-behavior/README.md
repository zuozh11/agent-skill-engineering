# 技能行为样例

这些样例检查实际交付、提问、加载范围与授权使用；脚本单元测试不能代替它们。`cases.json` 保存请求与人工判据，`prepare.mjs` 将指定版本的技能和原始样例复制到新的临时 Git 仓库，不改当前工作区、不安装插件、不调用模型 API。

```bash
node evals/skill-behavior/prepare.mjs prd-complete
node evals/skill-behavior/prepare.mjs standards-all /tmp/baseline/skills
```

每个样例使用独立的新执行上下文，只交给执行者生成的 `task.txt` 与其中指向的工作区。不要传入本文件、`checks`、预期问题、修改建议或其他样例的结论。需要用户回答的样例在首次关键提问处记录结果；不要让执行者替用户选择。

运行后由评估者按 `checks` 检查产物、工具调用和 Git 状态。记录技能版本、模型及推理设置、执行日期、通过/失败/未测、实际问题、加载的技能与参考文件、验证命令和产物位置。没有调用轨迹时，将加载范围与重复验证标为未测。

对比修改前后时使用相同请求、样例、模型和推理设置，分别生成全新工作区。行为质量通过后再比较耗时与可取得的 token 用量；输入文件字符数只代表文本体积。单次冒烟不能证明成功率提升或跨模型收益，未运行的模型和场景明确标为未测。
