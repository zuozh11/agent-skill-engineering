# Snapshot 评审

仅当用户只指定文件或目录、要求评审当前实现，且没有指定 commit、branch、PR、工作区变更或其他 diff 范围时，完整读取并使用本文件。只要存在可确定的 diff 范围，保持 diff 模式。

1. 将每个目标解析为仓库内真实存在的文件或目录；路径不存在、逃逸仓库或无法区分同名目标时停止并报告，不猜测。
2. 显式文件直接加入列表；目录优先使用 `rg --files --hidden -g '!.git/**'` 枚举受仓库忽略规则约束的文件并稳定排序，宿主没有 `rg` 时使用等价只读方式。二进制、生成物或无法读取的文件只可在说明原因后跳过，不得静默遗漏。
3. 记录当前 `HEAD`、目标路径、稳定文件列表和这些路径的 `git status --short`，审阅列表中当前工作区文件的完整内容。即使其中存在未提交改动，也不得静默缩小为 diff；只有用户明确要求「只看变更」时才切回 diff 模式。
4. 目录较大时按稳定文件列表分批，但所有批次仍属于同一次评审，必须覆盖完整列表后才能完成。

文件列表为空时立即停止并报告。
